# Latency-Compensated Edge-AI Visual Path Tracking for AGVs Under Degraded Floor Markings and Specular Glare

Academic Research Project | Perception Model Foundation (Phase 1)

---

## 1. Research Objective

Autonomous Guided Vehicles (AGVs) operating in industrial warehouse and factory environments rely on optical floor path markings for guidance. However, standard computer vision pipelines consistently fail under two prominent real-world phenomena:
1. **Specular Glare**: Highly reflective epoxy and polyurethane industrial floor coatings produce severe specular glare under high-bay lighting, washing out optical line features.
2. **Degraded Markings**: Mechanical abrasion from heavy forklift traffic, chemical spills, and tape wear cause significant path loss and structural discontinuities.

The long-term objective of this research is to develop an edge-optimized, latency-compensated vision navigation system that achieves robust, real-time path tracking under these degraded conditions.

## 3. Frozen System Architecture

### 3.1 End-to-End Pipeline Overview

```
Input Camera Frame (640 × 480 RGB)
  │
  ▼
Specular-Invariant Chromaticity Transform (SICT) Pre-filter
  │
  ▼
ROI Crop (y = 200 to 470, x = 0 to 640) & Resize to (288 × 384)
  │
  ▼
ShuffleNetV2-0.5× Backbone Feature Extractor
  │
  ▼
Row-Anchor Classification Head (18 rows × 101 classes)
  │
  ▼
Soft-Argmax Spatial Reconstruction & Presence Decoding
  │
  ▼
[Future Phases: IPM / Spline Fit ➔ Latency Compensation ➔ Pure Pursuit ➔ AGV Drive Base]
```

| :--- | :--- |

## 4. Mathematical Formulations

### 4.1 Specular-Invariant Chromaticity Transform (SICT)

For an RGB pixel $\mathbf{I}(u,v) = [R, G, B]^T$ with total intensity $S(u,v) = R + G + B$:

$$\begin{aligned}
r &= \frac{R}{S + \epsilon}, \quad g = \frac{G}{S + \epsilon}, \quad b = \frac{B}{S + \epsilon} \quad (\epsilon = 10^{-5})
\end{aligned}$$

Specular reflections compress color toward the equal-energy illuminant $(1/3, 1/3)$. The specular chromatic distance is:

$$\Phi(u,v) = \sqrt{\left(r(u,v) - \frac{1}{3}\right)^2 + \left(g(u,v) - \frac{1}{3}\right)^2}$$

The conditional filtering equation:

$$I_{\text{filtered}}(u,v) = \begin{cases}
I_{\text{ambient}}, & \text{if } S(u,v) \ge \Gamma_{\text{lum}} \text{ and } \Phi(u,v) \le \delta_{\text{spec}} \\
\alpha \cdot r(u,v) + \beta \cdot g(u,v), & \text{otherwise}
\end{cases}$$

**Frozen SICT Parameters:**
- $\Gamma_{\text{lum}} = 220.0$
- $\delta_{\text{spec}} = 0.05$
- $\alpha = 0.6$
- $\beta = 0.4$
- $I_{\text{ambient}} = 0.2 \times \text{frame-average intensity}$

All SICT parameters are centrally governed via `configs/default_config.yaml`.

### 4.2 Row-Anchor Labeling & Discretization

For each image, each anchor row $h_i$ ($i = 0, \dots, 17$) has either:
1. A horizontal path coordinate $u$ in $[0, 640)$, mapped to spatial grid cell:
   $$k = \left\lfloor \frac{u}{640} \times 100 \right\rfloor \in \{0, \dots, 99\}$$
2. **Absence Class**: If no path waypoint falls within $\pm 7.5\text{ px}$ of an anchor row, assign absence class index $100$ (representing token $101$).

### 4.3 Soft-Argmax Coordinate Decoding

Along row $h_i$, the continuous spatial coordinate $\hat{w}_i$ is derived via soft-argmax over spatial bins $j \in \{0, \dots, K-1\}$:

$$\hat{w}_i = \sum_{j=0}^{K-1} j \cdot \sigma(\mathbf{P}_{i,j}), \quad \text{where } \sigma(\mathbf{P}_{i,j}) = \frac{\exp(\mathbf{P}_{i,j})}{\sum_{k=0}^{K} \exp(\mathbf{P}_{i,k})}$$

Converting back to original frame horizontal pixel coordinates:

$$\hat{u}_i = \left(\frac{\hat{w}_i + 0.5}{100}\right) \times 640$$

The eventual F1 evaluation applies an **$8\text{-pixel}$ coordinate tolerance**.

### 4.4 Structural Training Loss

The total loss incorporates classification focal loss and structural continuity regularization:

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{focal}} + \lambda_{\text{smooth}} \sum_{i=1}^{M-1} |\hat{w}_{i+1} - \hat{w}_i|_1 + \lambda_{\text{curv}} \sum_{i=1}^{M-2} |(\hat{w}_{i+2} - \hat{w}_{i+1}) - (\hat{w}_{i+1} - \hat{w}_i)|_1$$

**Frozen Loss Parameters:**
- $\gamma_{\text{focal}} = 2.0$
- $\lambda_{\text{smooth}} = 0.5$
- $\lambda_{\text{curv}} = 0.75$

## 6. Training Configuration

All hyperparameters are controlled via `configs/default_config.yaml`:

- **Optimizer**: AdamW ($\beta_1 = 0.9, \beta_2 = 0.999$, weight decay $= 10^{-4}$)
- **Learning Rate**: Initial $4 \times 10^{-3}$, cosine annealing to $10^{-5}$
- **Batch Size**: 32
- **Epochs**: Maximum 50
